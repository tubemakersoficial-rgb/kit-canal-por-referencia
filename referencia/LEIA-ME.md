# Coloque aqui o vídeo de referência

- Um arquivo `.mp4` do vídeo que você quer usar como modelo de estilo (de preferência um vídeo que está indo muito bem no canal de referência), **ou**
- um arquivo `link.txt` com o endereço do vídeo ou do canal no YouTube (uma linha por link).

Se puder, coloque também 2 ou 3 capas do canal de referência (`capa1.jpg`…) para o Claude estudar a fórmula da capa.

Depois, abra o Claude Code na pasta do kit e diga: **"Analisa minha referência. Meu canal vai ser sobre [tema]."**

O que fica aqui é só para estudo e não vai para o vídeo final. Esses arquivos não sobem para o GitHub (estão no `.gitignore`).
