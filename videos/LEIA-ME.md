# Vídeos

Cada vídeo ganha uma pasta `NN-tema` (ex.: `01-primeiro-tema`), criada com:

```bash
python ferramentas/scripts/novo_video.py 01-primeiro-tema "C:/caminho/do/audio.wav"
```

Dentro dela ficam:
- `roteiro-narracao.md` e `narracao-ia.txt`: o roteiro e o texto para narrar;
- `roteiro-cenas.md`: a tabela de cenas, para aprovação;
- `work/`: a produção (scripts, quadros, recortes, clipes, animação). É pesada e não sobe para o GitHub;
- `tema-final.mp4`, `capa.jpg`, `capa-alternativa.jpg` e `descricao-youtube.md`: a entrega.
